## 🚀 Featured Projects

### 01. ConsultFlow — Consulting Management Platform

**A full-stack workspace for managing consulting operations, from client acquisition to invoicing and payments.**

🔗 **Repository:** [ConsultFlow](https://github.com/saqlainyaqoob/consultflow)


**Built with:** React 19 · TypeScript · Node.js · Express 5 · Apollo GraphQL · PostgreSQL · Docker

**Key engineering features**
- **Business workflows:** Leads, proposals, clients, projects, tasks, time tracking, invoices, expenses, and payments.
- **Authentication & authorization:** Secure sessions, HTTP-only cookies, role-based access control, and client-scoped data access.
- **API architecture:** GraphQL APIs, validated inputs, structured backend services, and PostgreSQL data access.
- **Real-time capabilities:** Socket.IO notifications and an email outbox workflow.
- **Document generation:** Proposal and invoice PDFs, including billing-related workflows.
- **Operational reliability:** Docker Compose services, database migrations, reproducible seed data, and health checks.

**Engineering focus:** Backend architecture, relational data modeling, security, business logic, and containerized development.

### 02. Commerce Dashboard — E-commerce Administration

**A data-driven dashboard for managing products, customers, orders, and inventory through a full-stack application.**

🔗 **[Live Demo](https://commerce-dashboard-web-app-frontend.vercel.app/login)** · **[GitHub Repository](https://github.com/saqlainyaqoob/commerce-dashboard-web-app)**

**Built with:** React 19 · Vite · Redux · Tailwind CSS 4 · Express.js · PostgreSQL · Socket.IO

**Key engineering features**
- **Commerce management:** Products, customers, orders, order items, and inventory alerts.
- **REST API backend:** Express services connected to PostgreSQL for data-driven operations.
- **Real-time communication:** Socket.IO integration.
- **Authentication:** JWT-based authentication and password hashing with bcrypt.
- **Database integration:** Relational data management and inventory-related workflows.
- **Deployment:** Vercel frontend deployment, Supabase-hosted PostgreSQL, and Docker-based local development.
- **Demo experience:** Read-only demo mode with write operations disabled while controls remain visible.

**Engineering focus:** Full-stack integration, CRUD workflows, database relationships, dashboard UX, authentication, and deployment.
